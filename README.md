## Featured Project

### Vision Checkout

A self-checkout system that detects Saudi retail products from a single image.

- **Model:** YOLO26m with two-stage training: pre-training on the RPC dataset (80K+ images), then fine-tuning on a custom, manually labeled Saudi retail dataset (857 images, 17 classes)
- **Results vs. YOLO11 baseline:** mAP50 improved from 37% to 46.4%; precision improved from 39% to 61.8%
- **Training:** Google Colab Enterprise (RTX PRO 6000)
- **Deployment:** Hugging Face Spaces with a Gradio interface and automatic receipt generation
